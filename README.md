FUNCTIONALITY
1.   This is a Python based project. It displays NDI sources in a optional grid of 2-by-2, 3-by-3 or 4-by-3 windows. The parent window is fixed at 'BottomWindowHint', therefore, when the sequence starts, one has to close or minimize all the top layer windows to see this main window.

2.   In addition to the automated grid of windows, it also includes a 'single-window-function' to display a supplementary window when any of the original grid-window crashes or closed due to bad NDI-source. When such function is selected then it must be placed at the desired location before selecting the NDI source. After the selection of the source it will vanish once and appear again in a frameless format after which it cannot be repositioned.

3.   In the start, if we select Single-window function, then default options of 2-by-2, 3-by-3 and 4-by-3 aer disbaled until this single-window is removed.

4.   No new default option is avilable until the last component window of the previously selected default option is still active in the main view. It is meant to avoid over-populating the main screen.

5.   Refresh button is there to enable deafult-option-buttons whenever required and applicable.
